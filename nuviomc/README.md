# NuvioMC — Remote Work Pack

חבילת עבודה לשרת NuvioMC, בנויה לעבודה **מרחוק דרך פאנל אירוח בדפדפן בלבד** (בלי SSH, בלי מחשב).
כל מה שכאן אפשר להעלות/להדביק מהטלפון או מדפדפן.

## מה יש כאן

| תיקייה | מה זה | איך מפעילים |
|--------|-------|--------------|
| `permissions/` | עץ ההרשאות המלא של LuckPerms | מדביקים פקודות בקונסולה של הפאנל |
| `staff/` | מועמדות לצוות: טופס, דרישות, ניקוד, תבניות תשובה | דיסקורד + העתקה־הדבקה |
| `vote/` | מערכת `/vote` מלאה | מעלים קבצים ב-File Manager + הקצאת פורט |

## סדר ביצוע מומלץ

1. **הרשאות** (`permissions/`) — הכי דחוף. בלי עץ הרשאות נקי כל השאר מתפרק.
2. **`/vote`** (`vote/`) — מביא שחקנים חדשים בחינם, וזה בדיוק ה"פרסום" שרצית.
3. **מועמדות צוות** (`staff/`) — נפתח רק **אחרי** שההרשאות מסודרות. אחרת נותנים לאנשים חדשים גישות שאתה לא שולט בהן.
4. **איוונטים + NPC** — פלאגין Java מותאם, נבנה בשלב הבא (ראה למטה).
5. **לאגים** — דורש הסתכלות על דוח חי מהשרת (ראה למטה).

## מה עוד ביקשת, ומה הסטטוס שלו

### 4. מערכת איוונטים + NPC עם בלון (פלאגין Java)
**סטטוס:** מוכן לבנייה, לא נבנה עדיין (בחרת להתחיל מ-1+2).

התכנון שסוכם:
- פלאגין Paper מותאם בשם `NuvioEvents`.
- `EventManager` שמנהל תור איוונטים — אפשר לתזמן רצף שלם אחד אחרי השני.
- איוונטים מובנים: Floor is Lava, Spleef, Last Man Standing, Sumo, Parkour Race, Build Battle, TNT Run.
- NPC בלובי (Citizens) שמחזיק בלון — לחיצה עליו:
  - יש איוונט פעיל → טלפורט ישיר לזירה.
  - אין איוונט → GUI עם לוח האיוונטים הקרובים.
- הפעלה רק ל-`nuvio.events.admin` — שחקן רגיל לא יכול להריץ/לעצור/לדלג.
- זירות נטענות מסכמות (schematics) ומתאפסות אוטומטית בין איוונטים.

**מה שצריך ממך כדי לבנות:** גרסת ה-Paper המדויקת של השרת, ואם Citizens כבר מותקן.

### 2. לאגים / שיפור ביצועים
**סטטוס:** לא ניתן לאבחן מכאן — צריך מדידה מהשרת החי. ניחושים בעיוור בקונפיגים עלולים להזיק יותר מלעזור.

מה שאתה יכול לעשות עכשיו מהפאנל (2 דקות):
```
/spark profiler start --timeout 300
```
לחכות 5 דקות בזמן שיש שחקנים, ואז:
```
/spark profiler stop
/spark tps
/spark health
```
תשלח לי את הלינקים שהפקודות מחזירות + פלט של `/plugins` ו-`/version`, ואני אחזיר רשימת תיקונים מדויקת לפי מה שבאמת אוכל את ה-TPS.

אם `spark` לא מותקן — הוא כבר מובנה ב-Paper החדש; אם לא, מעלים את ה-jar ל-`plugins/` דרך ה-File Manager ומפעילים מחדש.

### 3. פרסום
`/vote` (תיקיית `vote/`) הוא הצעד הראשון והמשמעותי ביותר — אתרי ההצבעה הם מקור התנועה החינמי הכי גדול לשרתים קטנים, והרשמה לכולם נעשית מהדפדפן. הרשימה המלאה ב-`vote/README.md`.
