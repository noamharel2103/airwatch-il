# הגדרת דיסקורד לצוות — NuvioMC

הכל נעשה מהאפליקציה בטלפון. 20 דקות עבודה.

## רולים

צור בסדר הזה — הסדר בדיסקורד קובע מי מנהל את מי, ורול לא יכול לנהל רול שמעליו.

```
Owner        — אדום כהה   #8B0000
Manager      — אדום       #C0392B
Admin        — כתום       #E67E22
Mod          — כחול       #3498DB
Helper       — צהוב       #F1C40F
Trial        — צהוב בהיר  #F9E79F
Builder      — ירוק       #27AE60
─────────────────────────────
MVP          — תכלת       #5DADE2
VIP+         — ירוק בהיר  #58D68D
VIP          — ירוק בהיר  #82E0AA
─────────────────────────────
Member       — אפור       #95A5A6
```

**חשוב:** תסמן ✅ **Display role members separately** לכל רולי הצוות בלבד.
זה מה שגורם לצוות להופיע בנפרד בראש רשימת החברים, ומייצר את המראה המסודר.

## הרשאות רולים — מה לא לתת

| הרשאה | למי מותר | למה |
|--------|----------|------|
| Administrator | Owner בלבד | עוקף הכל, בדיוק כמו `/op` |
| Manage Server | Owner, Manager | |
| Manage Roles | Owner, Manager | מי שיכול לנהל רולים יכול לקדם את עצמו |
| Manage Channels | Owner, Manager | |
| Ban Members | Mod ומעלה | |
| Kick Members | Helper ומעלה | |
| Timeout Members | Trial ומעלה | זה כלי המודרציה העיקרי בדיסקורד |
| Manage Messages | Trial ומעלה | מחיקת ספאם |
| Mention @everyone | Admin ומעלה | |

**אף פעם אל תיתן Administrator לרול שיש בו יותר מאדם אחד.**
זה שווה ערך מדויק ל-`/op` בשרת — כל מה שבנית מסביב הופך ללא רלוונטי.

## ערוצים

### קטגוריה: 📋 מועמדויות
| ערוץ | סוג | גישה |
|------|-----|------|
| `#הגשת-מועמדות` | Forum | כולם רואים, כולם פותחים פוסט |
| `#סטטוס-מועמדויות` | Text | קריאה לכולם, כתיבה לצוות בלבד |

**למה Forum ולא ערוץ רגיל:** כל הגשה מקבלת תגובות משלה, אפשר לסמן תגיות (בבדיקה / ראיון / התקבל / נדחה), והכל לא מתערבב.

**אם אתה משתמש ב-Google Forms במקום:** אז `#הגשת-מועמדות` הוא ערוץ טקסט רגיל עם הקישור בלבד, וכתיבה נעולה.

### קטגוריה: 🔒 צוות (מוסתרת מכולם)
| ערוץ | למי |
|------|-----|
| `#צוות-כללי` | Trial ומעלה |
| `#דיווחים` | Trial ומעלה |
| `#יומן-ענישות` | Trial ומעלה |
| `#דיוני-מועמדויות` | Mod ומעלה |
| `#ניהול` | Admin ומעלה |
| 🔊 `צוות` (קולי) | Trial ומעלה |

`#דיוני-מועמדויות` צריך להיות סגור מ-Trial ומ-Helper. הם עלולים לדון במועמדים שהם מכירים אישית.

### ערוץ שכדאי מאוד שיהיה: `#יומן-ענישות`
כל ענישה נרשמת בפורמט אחד:

```
שחקן: <שם>
פעולה: השתקה / העפה / באן
משך: <זמן>
סיבה: <סיבה>
תיעוד: <צילום מסך או קליפ>
מבצע: <שם איש הצוות>
```

זה נשמע כמו בירוקרטיה מיותרת עד הפעם הראשונה ששחקן טוען שנענש בלי סיבה, ויש לך שורה אחת שסוגרת את הוויכוח.

## אוטומציה כדאית

- **בוט טפסים** (Ticket Tool / Tickety) — אם אתה מעדיף מערכת טיקטים על פורום.
- **בוט לוגים** — שומר הודעות שנמחקו. שווה זהב כשמישהו כותב משהו ומוחק תוך שנייה.
- **DiscordSRV** — מחבר את צ'אט המשחק לדיסקורד ומסנכרן רולים אוטומטית עם דרגות LuckPerms. אם אתה מתקין אותו, אתה מקבל את סנכרון הדרגות בחינם ולא צריך לתת ידנית רולים לכל דונייטור.

## אבטחת השרת בדיסקורד

- **הפעל 2FA Requirement for Moderation** בהגדרות השרת. זה מכריח כל איש צוות עם הרשאות מודרציה להפעיל אימות דו־שלבי. חשבון צוות שנפרץ בלי זה הוא הדרך הכי נפוצה ששרתי דיסקורד נמחקים.
- **Verification Level: Medium לפחות.**
- **בדוק את רשימת הרולים פעם בחודש.** תחפש רולים שנוצרו ולא זכור לך שיצרת אותם.
