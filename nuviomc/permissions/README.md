# NuvioMC — עץ הרשאות LuckPerms

עץ הרשאות מלא, מוכן להדבקה בקונסולה של הפאנל. אין צורך ב-SSH ואין צורך לערוך קבצים ידנית.

## איך מריצים

בקונסולה של הפאנל, **בלי `/` בהתחלה** (הפאנל שולח לקונסולת השרת, ושם אין סלאש):

```
lp creategroup vip
```

בתוך המשחק כאדמין — **עם** `/`:

```
/lp creategroup vip
```

הרץ את הקבצים לפי הסדר: `01` → `02` → `03` → `04`.
אפשר להדביק כמה שורות ברצף; הקונסולה מריצה אותן אחת אחרי השנייה. אם הפאנל שלך חונק הדבקה של הרבה שורות, תדביק בקבוצות של ~15 שורות.

## מבנה הדרגות

### שחקנים
| דרגה | קבוצה | משקל | תיאור |
|------|-------|------|--------|
| Member | `default` | 0 | ברירת מחדל, כל מי שנכנס |
| VIP | `vip` | 10 | דונייטור בסיסי |
| VIP+ | `vipplus` | 20 | דונייטור בינוני |
| MVP | `mvp` | 30 | דונייטור עליון |

### צוות
| דרגה | קבוצה | משקל | תיאור |
|------|-------|------|--------|
| Builder | `builder` | 40 | בנייה בלבד, אין סמכויות ענישה |
| Trial | `trial` | 45 | חניך — תקופת ניסיון, ענישה קלה בלבד |
| Helper | `helper` | 50 | עוזר מלא |
| Mod | `mod` | 60 | מודרטור — באנים, ג'ייל, רולבק |
| Admin | `admin` | 80 | ניהול תוכן, כלכלה, WorldEdit |
| Manager | `manager` | 90 | ניהול צוות והרשאות |
| Owner | `owner` | 100 | אתה. `*` מלא |

`builder` יורש רק מ-`default` — בנאי הוא לא מודרטור.
`owner` **לא** יורש מ-`manager` בכוונה: הוא מקבל `*` ישירות, כדי שאף שלילת־הרשאה בעץ הצוות לא תוכל לחסום אותך.

## עקרונות שמנחים את העץ

1. **אין `*` לאף אחד חוץ מ-Owner.** כל דרגה אחרת מקבלת רשימת הרשאות מפורשת. זה מונע את התרחיש הקלאסי שבו מישהו מקבל דרגה ומגלה שיש לו גישה לפקודה שלא חשבת עליה.
2. **אף אחד לא מקבל `/op`.** אופרייטור עוקף את LuckPerms לגמרי — כל עץ ההרשאות הופך לחסר משמעות. קובץ `04` סוגר את זה.
3. **סמכות ענישה עולה בהדרגה.** Trial יכול להשתיק, Mod יכול לבאן. חניך חדש לא מקבל כפתור שמוחק שחקן מהשרת.
4. **`/fly` מוגבל לפי עולם.** MVP מקבל תעופה בלובי בלבד, לא בעולם השרידה. זה נעשה עם world context של LuckPerms, לא עם פלאגין נוסף.
5. **דברים שנראים תמימים ואינם:** `/heal`, `/god`, `/feed` באמצע קרב, `/nick` שמחקה שמות צוות. הקבצים מסמנים כל אחד מהם.

## אחרי ההרצה — לתת דרגות

```
lp user <שם> parent set owner
lp user <שם> parent set admin
lp user <שם> parent add vip
```

`parent set` מחליף את כל הדרגות. `parent add` מוסיף אחת נוספת (למשל שחקן שהוא גם Helper וגם VIP).

דרגה זמנית (טריאל של שבועיים, VIP לחודש):
```
lp user <שם> parent addtemp trial 14d
lp user <שם> parent addtemp vip 30d
```

קידום/הורדה לאורך מסלול הצוות:
```
lp user <שם> promote staff
lp user <שם> demote staff
```

## הגדרות שצריך לשנות ידנית (לא דרך פקודות)

### `plugins/LuckPerms/config.yml`
```yaml
enable-ops: false
auto-op: false
```
בלי זה, מי שמופיע ב-`ops.json` עוקף את הכל.

### `plugins/Essentials/config.yml`
מספר בתים לכל דרגה — LuckPerms נותן את ההרשאה, Essentials קובע את המספר:
```yaml
sethome-multiple:
  default: 1
  vip: 3
  vipplus: 5
  mvp: 10
```
וגם, כדי שהרשאות ה-warp לכל וורפ בנפרד יעבדו:
```yaml
per-warp-permission: true
```

## אימות אחרי ההרצה

```
lp group mod info
lp user <שם> permission check essentials.ban
lp user <שם> info
```

`permission check` הוא הכלי הכי שימושי כשמשהו לא עובד — הוא אומר לך **מאיזו קבוצה** ההרשאה הגיעה או נחסמה.
