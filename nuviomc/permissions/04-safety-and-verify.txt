# ============================================================
#  NuvioMC — שלב 4: סגירת הגישות ואימות
#  זה השלב שבגללו כל השאר שווה משהו. אל תדלג עליו.
# ============================================================

# ============================================================
#  1. גיבוי לפני הכל
# ============================================================
# יוצר קובץ ב-plugins/LuckPerms/ שאפשר להוריד מה-File Manager.
# אם משהו משתבש — lp import <שם הקובץ> מחזיר הכל.
lp export nuvio-backup-before-changes

# ============================================================
#  2. לבטל את מערכת ה-OP
# ============================================================
# זה החלק הכי חשוב בכל הקובץ.
# שחקן ב-ops.json עוקף את LuckPerms לחלוטין — יש לו הכל,
# ולא משנה מה כתוב בעץ ההרשאות שבנית עכשיו.

# קודם, לראות מי בכלל אופ:
deop @a

# @a תופס רק שחקנים מחוברים. תפתח את ops.json ב-File Manager
# ותוודא שהוא ריק — [] — כולל שמות של אנשים שלא מחוברים כרגע.
# אם יש שם מישהו שאתה לא מזהה, זו בעיית אבטחה, לא תקלה.

# אחר כך ב-plugins/LuckPerms/config.yml:
#   enable-ops: false
#   auto-op: false
# ואז הפעל מחדש את השרת מהפאנל.
# מכאן והלאה /op פשוט לא עושה כלום, וכל ההרשאות עוברות
# דרך LuckPerms בלבד.

# ============================================================
#  3. לתת לעצמך Owner
# ============================================================
# החלף <השם_שלך> בשם המשתמש שלך במיינקראפט.
lp user <השם_שלך> parent set owner

# ============================================================
#  4. אימות — לבדוק שהעץ באמת עובד
# ============================================================
# permission check אומר לך לא רק כן/לא, אלא מאיזו קבוצה
# ההרשאה הגיעה. זה הכלי לפתרון כל בעיית הרשאות.

# חניך לא אמור להיות מסוגל לבאן:
lp user <שם_חניך> permission check essentials.ban

# מודרטור כן:
lp user <שם_מודרטור> permission check essentials.ban

# אף אחד לא אמור לקבל op:
lp user <שם_מנג'ר> permission check minecraft.command.op

# סקירה כללית של קבוצה:
lp group mod info
lp group mod permission info

# סקירה של שחקן — מראה את כל הדרגות והמטא שלו:
lp user <שם> info

# ============================================================
#  5. עורך הרשאות בדפדפן — שימושי במיוחד מהטלפון
# ============================================================
lp editor

# הפקודה מחזירה קישור לעורך גרפי בדפדפן. אפשר לגרור
# הרשאות, לשנות קבוצות ולראות את כל העץ בצורה ויזואלית,
# ואז ללחוץ Apply והשינויים חוזרים לשרת.
# הקישור פעיל לזמן מוגבל.
#
# אזהרה: כל מי שיש לו את הקישור יכול לערוך את ההרשאות
# של השרת שלך. אל תשלח אותו בצ'אט ציבורי או בדיסקורד.

# ============================================================
#  6. תחזוקה שוטפת
# ============================================================
# גיבוי אחרי כל שינוי משמעותי:
lp export nuvio-backup-2026-08

# לראות מי קיבל איזו דרגה ומתי — LuckPerms שומר יומן פעולות:
lp log recent

# מי נתן דרגות בזמן האחרון (בדיקה חשובה אם משהו נראה חשוד):
lp log search group

# ============================================================
#  7. כלל הזהב שכדאי להישאר איתו
# ============================================================
# כשמישהו מבקש הרשאה נוספת, אל תוסיף לו אותה ידנית לשחקן.
# תוסיף אותה לקבוצה המתאימה, או שתעביר אותו לקבוצה אחרת.
#
# הרשאות ידניות לשחקנים בודדים הן בדיוק הדבר שגורם ל"אין
# לי מושג למה לבנאדם הזה יש גישה לזה" חצי שנה אחר כך.
#
# לבדוק אם הצטברו כאלה:
lp user <שם> permission info
